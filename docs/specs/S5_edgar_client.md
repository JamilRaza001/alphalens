Enforces SEC's 10 req/sec rate limit and `User-Agent: Name email@domain.com` requirement with **one shared limiter across all EDGAR hostnames**. Returns typed Pydantic models; cache-first reads make re-fetches idempotent and free of SEC network I/O after first hit. Pure I/O layer — no DB writes, no chunking, no state-machine logic (those live in S7, S6, S8 respectively). `EdgarClient.__init__` raises `ValueError` if the UA does not match `r"^[\w .'-]+ \S+@\S+\.\S+$"` (Name email@domain form).2. `RateLimiter` enforces ≤10 requests/sec across **all** EDGAR hostnames (`data.sec.gov` and `www.sec.gov`) via a **single shared instance**, never one per host.3. `list_filings()` calls `https://data.sec.gov/submissions/CIK{cik}.json` exactly once per CIK and returns only filings where `form ∈ form_types` AND `filing_date ∈ [date_from, date_to]`.4. Each returned `FilingMetadata` passes Pydantic validation: CIK zero-padded to 10 digits, accession in dashed format (`0000320193-24-000123`), `primary_doc_url` resolvable to `https://www.sec.gov/Archives/edgar/data/{int(cik)}/{accession_nodash}/{primary_doc_filename}`.5. `fetch_primary_doc()` calls R2 `head_object` first; on hit returns cached bytes via `get_object`; on miss fetches SEC, uploads to R2 with key `{cik}/{accession_nodash}.html` and `ContentType="text/html"`, then returns the bytes just uploaded.6. The internal `httpx.AsyncClient` is constructed with `timeout=httpx.Timeout(30.0, connect=10.0)` and `follow_redirects=True` (created in `__aenter__` if no `http_client` was injected).7. The internal aioboto3 R2 client is constructed via `aioboto3.Session().client("s3", endpoint_url=settings.r2_endpoint_url, region_name="auto", aws_access_key_id=..., aws_secret_access_key=..., config=Config(signature_version="s3v4"))` and entered/exited in `__aenter__` / `__aexit__`.8. Retries use `tenacity`: `@retry(retry=retry_if_exception_type(httpx.HTTPStatusError), wait=wait_exponential_jitter(initial=2, max=30), stop=stop_after_attempt(3), reraise=True)`. Retries only on response codes `429` and `5xx`; all other 4xx propagate immediately.9. Two sequential `fetch_primary_doc()` calls for the same filing produce exactly **one** SEC GET + **one** R2 PUT + **two** R2 HEADs + **one** R2 GET (verified by mock counters in unit test — second call is HEAD-then-GET, no upload).10. `async with EdgarClient(settings) as c: ...` closes both the `httpx.AsyncClient` and the aioboto3 client cleanly on exit (no warnings under `pytest -W error::ResourceWarning`).11. (`boto3` stays — used by `scripts/smoke_test.py`; both libs share the underlying `aiobotocore`/`botocore` and coexist cleanly.)## Gotchas- **User-Agent format is strictly enforced by SEC.** Generic UAs (`Mozilla/5.0`, empty, library defaults) trigger IP-level bans, not 4xx errors — silent throttling first, then refusal. Format must be `Some Name some@email.tld`. Validate with regex at init and fail fast. Ref: &lt;https://www.sec.gov/os/accessing-edgar-data&gt;.- **Accession has two formats.** Display/DB form: `0000320193-24-000123` (with dashes — what SEC returns and what `filings.accession_number` stores). URL-path form: `000032019324000123` (no dashes — needed for `/Archives/edgar/data/.../{nodash}/...` and as R2 key prefix). Convert at the boundary, never store the no-dash form.- **Rate limit is per-IP, global across hostnames.** A semaphore-per-host pattern would silently allow ~20 req/s combined and trigger 429s after a short burst. The token bucket must be **one instance**, acquired before every request regardless of target host.- **aioboto3 client is itself an async context manager.** You cannot store the result of `session.client(...)` as a plain attribute and `await` methods on it — you must enter the context. Pattern: store the *context manager* in `__init__`/`__aenter__`, call `await self._r2_ctx.__aenter__()` to get the live client, and `await self._r2_ctx.__aexit__(None, None, None)` in `aclose()`. Forgetting this manifests as `AttributeError: __aenter__` or `coroutine was never awaited` warnings.
